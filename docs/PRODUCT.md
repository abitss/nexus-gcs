# NEXUS GCS Product Constitution

## Goal
Build a rugged, offline-first Android ground-control station using AeroGCS Defence as a workflow reference, QGroundControl as the technical foundation, and Mission Planner as an advanced engineering reference.

## V0.1 scope
- One active UAV
- PX4
- MAVLink 2
- Tactical map
- Live telemetry
- Basic flight actions
- Basic waypoint mission planning
- Health
- Alerts
- Payload video surface
- Vehicle overview
- Offline operation

## Primary navigation
1. Flight
2. Plan
3. Health
4. Payload
5. Analyze
6. Vehicle

## Non-goals for V0.1
- Multi-UAV control
- Cloud dependency
- Complete report engine
- Full engineer tooling rewrite
- Reimplementation of MAVLink/QGC core
